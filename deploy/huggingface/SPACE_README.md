# MathExaminer AI (demo)

The public demo of [MathExaminer AI](https://github.com/WHYNOT-LUO/mathexaminer-ai), which marks
handwritten A-Level maths step by step against a Cambridge-style mark scheme and sends uncertain
work to a teacher.

Log in as `student@demo.school` or `teacher@demo.school` with any password. "Stationary points of
a cubic" is real homework, marked once by the AI and replayed here; the other assignments are
labelled example data.

This Space is a backup copy of the main demo at
[mathexaminer-ai-demo.streamlit.app](https://mathexaminer-ai-demo.streamlit.app). The code, tests
and documentation live on [GitHub](https://github.com/WHYNOT-LUO/mathexaminer-ai).
